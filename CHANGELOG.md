# Changelog

All notable user-visible changes to the nzbfast TOS application package.

## 1.3.1-1 — 2026-11-11

### Added
- First release. nzbfast (`nzbfast/nzbfast:1.3.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8068 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/nzbfastdocker/`.
